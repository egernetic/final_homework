Git

  • git init - команда используется для инициализации проекта как репозитория git.
  • git commit - команда совершает коммит — «закрепляет» промежуточные результаты.
  • git pull - команда используется для извлечения только что полученной информации и ее загрузки в локальный репозиторий.
  • git push - команда используется для отправки закоммиченных файлов в удаленный репозиторий в указанной ветке.
